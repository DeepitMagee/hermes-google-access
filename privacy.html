Privacy policy

Hermes Google Workspace — last updated 2 October 2026

Who this covers

Hermes Google Workspace is a private, single-user application operated by Deepit Magee ("the operator"). It has exactly one user: the operator himself. It is not distributed, published or made available to anyone else.

What data it accesses

With the operator's explicit consent, the application accesses data belonging to the operator's own Google Account: email messages and labels (Gmail), calendar events, files in Google Drive, Google Docs and Sheets documents, and contacts (read-only). It accesses no other person's Google data.

How data is used

Data is used solely to carry out tasks the operator requests of his own agent software — for example, reading a message, drafting a reply, checking a calendar, or editing one of his own documents. It is not used for advertising, profiling, analytics, or training machine-learning models.

How data is stored

OAuth credentials are stored locally, in files on the operator's own computers, protected by the operating system's file permissions. Email, calendar and document content is processed in memory as tasks are carried out. Copies of data persist only where the operator's own workflows put them, on his own machines or in his own accounts.

Sharing and disclosure

Google user data is never sold, rented, shared or transferred to any third party. It is transmitted only to Google's own APIs, which is how the application performs the tasks requested of it. No third-party analytics or advertising services are used on this site or in the application.

Limited Use disclosure

This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Access can be revoked at any time at myaccount.google.com/permissions, which immediately ends the application's ability to read or write any Google data. Locally stored credentials are deleted on request. Any request to delete stored data can be made to the contact address below and will be actioned promptly.
